# Telegram Bot Admin — Быстрый Старт

## Что Это?

Пользователи отправляют заявки через Telegram-бот. Вы как админ можете видеть все заявки через простой API и создавать из них заказы.

## Как Это Работает?

```
Пользователь в Telegram → Отправляет заявку → API → Вы видите данные
```

## API для Админа

### 1. Получить все заявки

```bash
curl http://localhost:4000/api/telegram/forms
```

**Ответ:**
```json
{
  "count": 2,
  "forms": [
    {
      "userId": 123456789,
      "userName": "Ivan",
      "service": "🔧 Техническое обслуживание",
      "serviceDetails": "Замена масла и фильтров",
      "bikeBrand": "Yamaha YZF-R1",
      "phone": "+380501234567",
      "submittedAt": "2024-11-15T10:30:00Z"
    },
    {
      "userId": 987654321,
      "userName": "Anna",
      "service": "🎨 Кузовные работы",
      "serviceDetails": "Покраска панели",
      "bikeBrand": "Honda CB500",
      "phone": "+380951234567",
      "submittedAt": "2024-11-15T10:45:00Z"
    }
  ],
  "timestamp": "2024-11-15T10:50:00Z"
}
```

### 2. Очистить заявки (после обработки)

```bash
curl -X POST http://localhost:4000/api/telegram/forms/clear
```

**Ответ:**
```json
{
  "message": "Cleared 2 form(s)",
  "timestamp": "2024-11-15T10:50:00Z"
}
```

### 3. Проверить, работает ли бот

```bash
curl http://localhost:4000/api/telegram/status
```

**Ответ:**
```json
{
  "initialized": true,
  "hasToken": true,
  "timestamp": "2024-11-15T10:50:00Z"
}
```

## Сценарии Использования

### Сценарий 1: Проверить новые заявки утром

```bash
# Получить все заявки
curl http://localhost:4000/api/telegram/forms

# Обработать данные... создать заказы и т.д.

# Очистить уведомления
curl -X POST http://localhost:4000/api/telegram/forms/clear
```

### Сценарий 2: Регулярно проверять заявки (каждые 5 минут)

Добавить в cron или скрипт:
```bash
*/5 * * * * curl -s http://localhost:4000/api/telegram/forms | jq '.count' >> ~/telegram-forms-count.log
```

### Сценарий 3: Интегрировать в фронтенд-панель

Позже, когда будет WebSocket, админ-панель будет автоматически показывать новые заявки.

## Структура Данных Заявки

| Поле | Тип | Описание |
|------|-----|---------|
| `userId` | number | ID пользователя в Telegram |
| `userName` | string | Имя пользователя |
| `service` | string | Выбранная услуга (с иконкой) |
| `serviceDetails` | string \| null | Описание (если спрашивали) |
| `bikeBrand` | string | Марка/модель мотоцикла |
| `phone` | string | Номер телефона |
| `submittedAt` | string | Когда была отправлена заявка |

## Примеры Реальных Заявок

### Пример 1: Техническое обслуживание (с описанием)

```json
{
  "userId": 123456789,
  "userName": "Ivan",
  "service": "🔧 Техническое обслуживание",
  "serviceDetails": "Замена масла, фильтров и свечей",

  "phone": "+380501234567",
```

3. Позвонить пользователю по номеру

## Интеграция с Фронтенд-Панелью

### Для текущей версии (без WebSocket):

1. Добавить вкладку "Заявки из Telegram" на админ-панель
2. Каждые 5-10 секунд выполнять `GET /api/telegram/forms`
3. Показывать новые заявки красной подсветкой
4. При клике — создать заказ прямо из заявки

### Для будущей версии (с WebSocket):

1. Админ-панель подпишется на WebSocket события
2. При новой заявке — реал-тайм уведомление
3. Кнопка "Создать заказ" прямо в нотификации

## Текущие Ограничения

⚠️ **Заявки хранятся только в памяти** — при перезагрузке сервера заявки теряются

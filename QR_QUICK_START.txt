1️⃣  ЗАПУСК БОТА:
    $ npm run dev

2️⃣  СМОТРИТЕ КОНСОЛЬ:
    Вы увидите QR код в терминале

3️⃣  ДОБАВЬТЕ БОТА:
    ✓ Отсканируйте QR код камерой
    ✓ Откройте выданную ссылку https://t.me/your_bot_name
    ✓ Найдите бота вручную в Telegram

4️⃣  ТЕСТИРУЙТЕ:
    → Отправьте /start
    → Получите ответ "Бот добавлен успешно ✓"

════════════════════════════════════════════════════════════════

ОШИБКИ:

❌ "TELEGRAM_BOT_TOKEN is not set"
   → Добавьте токен в .env.local:
     TELEGRAM_BOT_TOKEN=9265019209:AAEGNwBh9ZxJoBQHrFFCHeNWELiUTxEalIU

❌ QR код не показывается
   → Проверьте соединение с интернетом
   → Проверьте логи: grep "Telegram Bot QR Code"

❌ Бот не отвечает
   → Переперезагрузите: npm run dev
   → Проверьте токен еще раз

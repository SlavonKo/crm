# Telegram Bot Setup

Этот документ описывает, как настроить и запустить Telegram бота в приложении CRM.

## Требования

- Token Telegram бота (получить можно через [@BotFather](https://t.me/BotFather))
- Node.js и npm
- Интернет соединение для подключения к Telegram API

## Шаг 1: Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Вы получите токен в формате: `9265019209:AAEGNwBh9ZxJoBQHrFFCHeNWELiUTxEalIU`

⚠️ **Важно:** Токен — это скрытая информация. Никогда не выкладывайте его в публичные репозитории!

## Шаг 2: Добавление токена в .env.local

Откройте файл `.env.local` в корне проекта и добавьте:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_здесь
```

Пример:
```env
TELEGRAM_BOT_TOKEN=9265019209:AAEGNwBh9ZxJoBQHrFFCHeNWELiUTxEalIU
```

## Шаг 3: Запуск приложения

Обычный запуск включает бота:

```bash
npm run dev
```

## Использование бота

### Способ 1: Отсканируйте QR код
- В консоли терминала откройте терминальное приложение с поддержкой камеры
- Отсканируйте QR код при помощи смартфона
- Откроется Telegram с вашим ботом

### Способ 2: Перейдите по ссылке
- Скопируйте ссылку из консоли
- Откройте её в браузере
- Будете перенаправлены в Telegram

### Способ 3: Поиск вручную
- Откройте Telegram
- Найдите бота по имени (которое вы дали при создании)
- Нажмите кнопку "Start"

После добавления:
1. Отправьте команду `/start`
2. Бот ответит: "Бот добавлен успешно ✓"

## Структура

- **Backend модуль:** `backend/src/telegram-bot.ts` — логика обработки сообщений
- **Main server:** `backend/src/index.ts` — инициализация бота при запуске
- **Environment:** `.env.local` — хранит `TELEGRAM_BOT_TOKEN`

## Команды бота

| Команда | Описание |
|---------|---------|
| `/start` | Инициализирует бота и показывает приветственное сообщение |

## Отключение бота

Если вы не хотите запускать бота:

1. Удалите или закомментируйте `TELEGRAM_BOT_TOKEN` в `.env.local`
2. Перезагрузите приложение (`npm run dev`)

Бот не будет инициализирован, и приложение продолжит работать нормально.

## Возможные проблемы

### Ошибка: "TELEGRAM_BOT_TOKEN is not set"
**Решение:** Убедитесь, что добавили `TELEGRAM_BOT_TOKEN` в `.env.local` и перезагрузили приложение.

### Ошибка: "409 Conflict: terminated by other getUpdates request"
**Причина:** Несколько экземпляров бота пытаются получать updates с одного токена одновременно.

**Решение в development:**
1. Остановите процесс `npm run dev` (Ctrl+C или Cmd+C)
2. Подождите 3-5 секунд, чтобы все соединения закрылись
3. Перезапустите `npm run dev`

**Почему это происходит:**
- При использовании `npm run dev` с `tsx watch`, когда вы редактируете файлы, процесс перезагружается
- Старый процесс может не закрыть polling соединение достаточно быстро
- Новый процесс пытается начать polling, но старый всё ещё активен

**Предотвращение:**
- Всегда останавливайте сервер перед редактированием backend файлов (особенно telegram-bot.ts)
- Используйте `npm run dev` только один раз (не запускайте несколько экземпляров)
- Если проблема повторяется, проверьте, нет ли других процессов Node.js: `lsof -i :4000`

### Бот не отвечает
**Решение:** 
- Проверьте, что токен скопирован корректно
- Убедитесь, что интернет соединение активно
- Проверьте логи в консоли: `[telegram-bot] Polling error`

### Ошибка валидации типов TypeScript
**Решение:** Убедитесь, что установлены зависимости:
```bash
cd backend
npm install
```

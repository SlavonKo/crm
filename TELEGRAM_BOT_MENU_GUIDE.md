# Telegram Bot Menu System — Руководство

## Обзор

Telegram-бот теперь поддерживает полноценную систему меню и форм для сбора заявок от пользователей. Пользователи могут выбрать услугу, указать детали, марку мотоцикла и телефон. Админ видит все заявки через API.

## Структура Бота

### Главное меню (Main Menu)
При отправке `/start` или нажатии кнопки "📋 Главное меню" пользователь видит список услуг:

```
🔧 Техническое обслуживание
🔩 Ремонт мотоциклов
🎨 Кузовные работы
📡 Установка/доработка оборудования
⚙️ Подготовка к сезону
🛞 Ремонт дисков
⛽ Ремонт/настройка топливной
```

### Поток Диалога

#### 1. Услуга требует описания (🔧, 🔩, 🎨, 📡):
```
Пользователь выбирает услугу
    ↓
Бот просит: "Опишите подробнее, что нужно сделать"
    ↓
Пользователь вводит описание (например: "Замена масла, фильтров")
    ↓
Бот просит: "Укажите марку и модель мотоцикла"
    ↓
Пользователь вводит (например: "Yamaha YZF-R1")
    ↓
Бот просит: "Поделитесь своим номером телефона"
    ↓
Пользователь вводит телефон
    ↓
Заявка отправляется, пользователь видит подтверждение
```

#### 2. Услуга БЕЗ описания (⚙️, 🛞, ⛽):
```
Пользователь выбирает услугу
    ↓
Бот просит: "Укажите марку и модель мотоцикла"
    ↓
[Остальное как выше]
```

### Навигация

- На любом этапе пользователь может нажать **"📋 Главное меню"** и вернуться в главное меню
- После завершения формы пользователь автоматически возвращается в главное меню
- История диалога НЕ сохраняется, начинается новая сессия

## Backend API

### Структура заявки (Form)

```typescript
{
  userId: number;
  userName: string;
  service: string;              // "🔧 Техническое обслуживание", и т.д.
  serviceDetails: string | null; // Пользовательское описание (если требуется)
  bikeBrand: string;             // "Yamaha YZF-R1"
  phone: string;                 // "+380501234567"
  submittedAt: Date;
}
```

### GET /api/telegram/forms

Получить все поступившие заявки.

**Ответ:**
```json
{
  "count": 2,
  "forms": [
    {
      "userId": 123456789,
      "userName": "Ivan",
      "service": "🔧 Техническое обслуживание",
      "serviceDetails": "Замена масла и фильтров",
      "bikeBrand": "Yamaha YZF-R1",
      "phone": "+380501234567",
      "submittedAt": "2024-11-15T10:30:00Z"
    }
  ],
  "timestamp": "2024-11-15T10:35:00Z"
}
```

### POST /api/telegram/forms/clear

Очистить список заявок (после того как админ их обработал).

**Ответ:**
```json
{
  "message": "Cleared 2 form(s)",
  "timestamp": "2024-11-15T10:35:00Z"
}
```

### GET /api/telegram/status

Проверить статус бота.

**Ответ:**
```json
{
  "initialized": true,
  "hasToken": true,
  "timestamp": "2024-11-15T10:35:00Z"
}
```

## Для Фронтенда (Интеграция позже)

Когда будет реализован WebSocket, админ-панель сможет:

1. **Подписаться на новые заявки** через WebSocket событие
2. **Видеть заявки в реал-тайм** по мере их поступления
3. **Создавать заказ/наряд** из заявки одной кнопкой

На данный момент можно использовать `GET /api/telegram/forms` с polling'ом.

Примеры логов:

```

```

## Отладка

### Проблема: Бот не отвечает

1. Проверьте статус: `GET http://localhost:4000/api/telegram/status`
2. Если `initialized: false` — перезапустите сервер
3. Убедитесь, что `TELEGRAM_BOT_TOKEN` установлен в `.env.local`

### Проблема: Пользователь не видит главное меню

Возможные причины:
- Пользователь не отправил `/start`
- Сессия пользователя потеряна (редко, обычно в памяти)
- Нажмите "📋 Главное меню" для возврата

### Проблема: Заявка не сохранилась

1. Проверьте логи в консоли и файле логов
2. Убедитесь, что пользователь прошел все 3-4 шага формы
3. Проверьте ответ через `GET /api/telegram/forms`

## Текущие Ограничения

- ✓ Заявки хранятся **только в памяти** (теряются при перезагрузке сервера)
- ✓ Нет **реал-тайм уведомлений** админу (будет добавлено через WebSocket)
- ✓ Нет **сохранения в БД** (планируется)
- ✓ Нет **создания заказа прямо из заявки** (планируется)

## Следующие Шаги

1. **WebSocket интеграция** — реал-тайм уведомления админу
2. **Сохранение в БД** — постоянное хранение заявок
3. **Создание заказа из заявки** — админ сможет создать наряд одной кнопкой
4. **Telegram уведомления админу** — админ получит сообщение в Telegram при новой заявке

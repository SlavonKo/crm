## ✅ Backend API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|---------|
| GET | `/api/telegram/status` | Статус бота (инициализирован ли, есть ли токен) |
| GET | `/api/telegram/forms` | Получить все поступившие заявки |
| POST | `/api/telegram/forms/clear` | Очистить список заявок |
| GET | `/api/telegram/qr` | Получить QR код бота (с кешированием) |

## ✅ Структура Данных

### UserSession
```typescript
{
  userId: number;           // Telegram user ID
  chatId: number;           // Telegram chat ID
  userName: string;         // Имя пользователя
  state: DialogState;       // Текущее состояние диалога
  selectedService: string;  // Выбранная услуга
  serviceDetails: string;   // Описание (если нужно)
  bikeBrand: string;        // Марка/модель мотоцикла
  phone: string;            // Телефон пользователя
  createdAt: Date;          // Время создания сессии
}
```

### DialogState
```typescript
type DialogState = 
  | 'main_menu'
  | 'service_selected'
  | 'asking_service_details'
  | 'asking_bike_brand'
  | 'asking_phone'
  | 'form_complete';
```

### ServiceCategory
```typescript
{
  id: string;              // Уникальный ID
  name: string;            // "🔧 Техническое обслуживание"
  icon: string;            // "🔧"
  requiresDetails: boolean; // Требуется ли описание?
}
```

## 📊 Поток Диалога

```
/start
  ↓
[Главное меню] — выбрать услугу
  ↓
├─→ Услуга требует описания (🔧, 🔩, 🎨, 📡)
│    ├─→ "Опишите подробнее"
│    ├─→ "Укажите марку мотоцикла"
│    └─→ "Укажите телефон"
│
└─→ Услуга без описания (⚙️, 🛞, ⛽)
     ├─→ "Укажите марку мотоцикла"
     └─→ "Укажите телефон"

↓
Форма завершена → Заявка сохранена → Возврат в меню
```

## 🔧 Использование

```bash

```


```
[telegram-bot] ✓ Telegram bot initialized successfully
[ai-proxy] ✓ Listening on http://localhost:4000
```

### Шаг 3: Отправить `/start` боту в Telegram
- Откройте Telegram
- Найдите `@kirill_service_moto_bot` (или ваш бот)
- Отправьте `/start`
- Должны увидеть главное меню

### Шаг 4: Заполнить форму
- Выберите любую услугу
- Заполните требуемые поля
- Завершите форму

### Шаг 5: Проверить API
```bash
curl http://localhost:4000/api/telegram/forms
```

Должны увидеть вашу заявку в ответе.
